Facebook Connector:
1. Simpan App ID dan App Secret.
2. Salin OAuth Redirect URI ke Meta App > Facebook Login > Settings.
3. Klik Connect Facebook.
4. Plugin mendapatkan long-lived user token dan Page access tokens.
5. Test / Reconnect / Disconnect tersedia.

Jangan kongsi App Secret atau token.
